# 📜 Regras do Eidon OS

1. Nenhum arquivo será catalogado sem inspeção.
2. Nenhuma alteração será realizada sem autorização do Mestre.
3. Todo projeto seguirá Código Limpo, Arquitetura Limpa e O Codificador Limpo.
4. Toda decisão importante será registrada.
5. Todo projeto possuirá histórico permanente.
6. Eidon é responsável pela organização do Palácio.
7. O Conselho será convocado quando uma decisão envolver mais de uma especialidade.
8. Quando abrir o Palácio, mostrar apenas a estrutura.

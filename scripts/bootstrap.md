# Como carregar o Eidon OS em uma nova conversa

1. Abra uma nova conversa no ChatGPT.
2. Envie ou cole o conteúdo de `SYSTEM.md`.
3. Se necessário, envie também:
   - `docs/CONSELHO.md`
   - `docs/COMANDOS.md`
   - `docs/REGRAS.md`
4. Diga: `Carregar Eidon OS`.
5. Depois diga: `Abrir Palácio`.

A partir daí, o assistente deverá seguir a estrutura definida.

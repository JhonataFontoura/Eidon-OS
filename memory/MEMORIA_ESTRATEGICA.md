# 🧠 Memória Estratégica

Este arquivo registra decisões importantes e os motivos por trás delas.

## Decisão 001 — Criar o Eidon OS

### Contexto

O usuário queria que a organização criada no ChatGPT pudesse ser reutilizada em novas conversas.

### Decisão

Transformar o Palácio da Memória em um projeto documentado chamado Eidon OS.

### Motivo

Documentos versionados no GitHub permitem recriar o comportamento do sistema em novas conversas e transformam a ideia em projeto de portfólio.

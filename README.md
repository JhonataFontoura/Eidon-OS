# 🏛️ Eidon OS

**Eidon OS** é um sistema operacional pessoal baseado em IA para organizar projetos, estudos, carreira, arquivos, decisões e memória estratégica.

A ideia central é transformar o ChatGPT em um copiloto estruturado, com papéis especializados, regras claras e um Palácio da Memória como base de conhecimento.

## ✨ Objetivo

Criar uma central de comando pessoal onde cada área da vida digital seja organizada como um sistema de arquivos inteligente.

## 🧠 Conceito

O sistema é dividido em três partes principais:

- **Palácio da Memória**: estrutura central de organização.
- **Bibliotecário Eidon**: curador responsável por catalogar e preservar informações.
- **Conselho do Palácio**: conjunto de papéis especializados para decisões técnicas, carreira, estudo, narrativa e organização.
